# Auto Email monitor

The status page for a private cold-outreach pipeline, published so the owner
can keep it on a phone home screen.

**This repository is generated.** It is overwritten by the `Auto Email monitor`
workflow in the private pipeline repository on every run - edits made here will
be lost.

## What is and is not here

Deliberately published: run states, counts, rates, ages, and the health alerts
derived from them.

Deliberately absent: business names, email addresses, lead identifiers, message
contents. Those never leave the private repository. Everything in this repo is
aggregate numbers about a pipeline, not data about anybody.

The page is served with `noindex, nofollow`.
